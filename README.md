# Ритм — личный дневник тренировок

## Онлайн: ПК и телефон

Сайт: https://dynochris.github.io/ritm-training-diary/

Сайт опубликован на GitHub Pages, авторизация работает через Firebase Authentication, общий дневник хранится в Firebase Realtime Database проекта `ritm-dynochris` (европейский регион). Вход по логину `dynochris` и паролю, заданному владельцем; пароль отсутствует в исходниках. Firebase использует внутренний технический адрес учётной записи — вводить его не нужно.

Открой один и тот же адрес на ПК и телефоне. Записи обновляются в реальном времени. Изменения с устаревшей версией блокируются, чтобы не затереть сохранение с другого устройства. При отсутствии интернета сохранение требует восстановления связи. Кнопка «Выйти» завершает сеанс на этом устройстве.

Публичные настройки подключения в `runtime-config.js` не дают доступа к данным. Правила в `database.rules.json` разрешают доступ только UID владельца. Корень базы и другие пользователи закрыты. История, резервные копии и служебные журналы исключены из Git.

Публикация сайта: push в `main` запускает `.github/workflows/pages.yml`, который размещает только HTML/CSS/JS и иконку. Обновление правил базы: `firebase deploy --only database --project ritm-dynochris`. База уже содержит историю владельца; исходники её не содержат.

## Локальная версия

Ниже описан отдельный локальный режим для запуска без интернета. Его файл данных не синхронизируется с Firebase; для общего дневника используй онлайн-адрес.

Дважды нажми **Запустить.cmd**. Сайт откроется в браузере по адресу http://127.0.0.1:8791. Окно запуска оставь открытым, пока пользуешься дневником. Для остановки нажми Ctrl+C в этом окне.

На этом компьютере Python уже установлен. Дополнительные библиотеки, интернет и аккаунт не нужны. На другом компьютере требуется Python 3.10 или новее.

На рабочем столе есть ярлык **Ритм — тренировки** с зелёной иконкой. Он открывает сайт, при необходимости запускает сервер в фоне и использует работающий сервер при повторном нажатии. Консольное окно для этого способа не требуется. Ярлык связан с этой папкой: после перемещения папки его нужно обновить.

## Как пользоваться

- Выбери день в календаре и нажми **+** или **Добавить тренировку**.
- Календарь — непрерывная лента недель. Колёсико плавно двигает её по пикселям в обе стороны, месяцы подгружаются автоматически. Шапка и дни недели остаются на месте; стрелки и «Сегодня» плавно перемещают ленту к нужной дате. Статистика относится к месяцу в шапке календаря.
- Выбери вид тренировки радиокнопкой, при желании напиши короткую заметку и сохрани.
- Время новой тренировки автоматически ставится по текущим часам компьютера. Его можно изменить в поле времени через значок часов; кнопка «Сейчас» снова выставляет текущее время. При редактировании сохраняется время записи. Старым тренировкам добавлено примерное вечернее время между 20:00 и 22:00; знак «≈» отличает его от точного времени. Записи одного дня отображаются по времени.
- Иконки появятся в ячейке этого дня. Несколько записей одного вида показывают одну иконку; все записи доступны справа.
- Карандаш рядом с записью позволяет изменить её вид, дату и описание. Корзина удаляет запись после подтверждения.
- Если описание состоит из целых неотрицательных чисел через запятую, сайт автоматически показывает их сумму. Например, `30, 35, 50, 35, 50` → **Всего: 200**. Сумма видна при вводе и у сохранённой записи, включая старые записи.
- **+** рядом с «Виды тренировок» добавляет свой вид с названием и одной из трёх иконок.
- Карточка «Тренировочных дней за всё время» считает все уникальные даты с тренировками: турник, отжимания и ходьба в один день считаются одним тренировочным днём. Этот итог не меняется при прокрутке календаря. Вторая карточка показывает активные дни и число записей упражнений за месяц в шапке календаря. Серия — последовательные дни с тренировками до сегодня или до вчера, если сегодня записей ещё нет. Будущие записи не увеличивают серию.
- **Скачать копию данных** сохраняет резервную копию JSON в загрузки браузера.

## Где данные

Все записи и виды тренировок сохраняются в **data/workouts.json**, в этой папке. Файл создаётся при первом запуске. Данные остаются после закрытия сайта и перезагрузки компьютера. В локальном режиме записи не отправляются в облако. В онлайн-режиме Firebase хранит сеанс в браузере и записи в общей базе. Аналитика не подключена.

Чтобы перенести дневник, останови сервер и скопируй всю папку вместе с `data`. Для восстановления резервной копии останови сервер, сохрани текущий файл отдельно и помести копию на место `data/workouts.json`.

Не открывай `index.html` напрямую: браузеру нужен локальный сервер для записи в файл. Используй **Запустить.cmd**. Если порт 8791 занят другим приложением, запусти `python server.py --port 8792 --open` в этой папке.

Сервер доступен только на этом компьютере. Сохранение атомарное: новая версия полностью записывается перед заменой файла. Если дневник изменён в другой вкладке, сайт попросит повторить сохранение, чтобы избежать потери записей.

## Файлы

`index.html` — страница, `styles.css` — оформление, `app.js` — календарь и формы, `server.py` — локальное сохранение. Иконки упражнений нарисованы в SVG внутри `app.js`.
